## Major features completed

1. **Portable Ollama model cache** (committed, verified live).
   - `model_cache.py:ensure_model(name)` manages cache in `../AI Model/`
     sibling folder (D:\lesson_table_pipeline\AI Model).
   - Cache mirrors Ollama's store layout (manifests/ + blobs/).
   - Auto-import/export on startup; all failures silent (AI optional).
   - Tested: qwen3:8b (5.2 GB) exported to cache successfully.
   - Purpose: copy AI Model/ folder to new PC, avoid 5 GB re-download on
     first run.

2. **get_model.bat** (at pipeline root, NOT in repo, gitignored).
   - Pulls a model via `ollama pull` (default qwen3:8b, arg overrides).
   - Calls `model_cache.export_to_cache` to save to AI Model/.
   - Enables pre-loading models for distribution/offline setups.
   - Smoke-tested successfully.

3. **Flash-drive portability workflow**.
   - Copy entire lesson_table_pipeline folder (or just AI Model/) to
     flash drive (~6 GB, NTFS/exFAT; FAT32 cannot hold 5.2 GB blob).
   - On new PC: keep AI Model/ sibling to Data Extractor, install Ollama,
     run app → auto-import, no model download.
   - Users can pre-stage AI Model/ folder for distribution.

4. **Menu trimmed and stable**.

   - Menu numbering is now locked (no more shifts expected).

## Decisions

- **Cache location:** Sibling folder AI Model/ (outside repo root, alongside
  Data Extractor). User offered to move inside repo; decision pending.
- **Silent failures:** All model cache operations (import/export/pull) fail
  silently (logs only); extraction proceeds without AI if cache ops fail.
  Rationale: AI is optional; model distribution should not block the app.
- **Flash-drive format:** NTFS or exFAT. FAT32 rejected (5.2 GB qwen3 blob).
